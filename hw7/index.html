Executive Summary & Research Directives

In data science, applied statistics, and cybersecurity threat analysis, establishing whether two random variables $X$ and $Y$ are statistically independent is fundamental. Whether evaluating if firewall rule breaches are independent of attack vectors, if authentication bypasses are correlated with MFA protocols, or if malware persistence mechanisms depend on execution privilege tiers, the contingency table serves as the primary analytical structure.

This work develops an end-to-end computational and theoretical framework addressing the core assignments:

  1. Programmatic Construction of Contingency Tables: Computation of observed frequencies $n_{ij}$, marginal row frequencies $n_{i\cdot}$, marginal column frequencies $n_{\cdot j}$, joint empirical probabilities $p_{ij} = n_{ij}/N$, row-conditional distributions $P(Y = y_j \mid X = x_i)$, and column-conditional distributions $P(X = x_i \mid Y = y_j)$.
  2. Theoretical Expected Frequencies Under Independence: Derivation of $e_{ij} = \frac{n_{i\cdot} n_{\cdot j}}{N}$ under the null hypothesis $H_0: P(X, Y) = P(X)P(Y)$, computation of raw residuals $(n_{ij} - e_{ij})$, Pearson residuals $r_{ij} = \frac{n_{ij} - e_{ij}}{\sqrt{e_{ij}}}$, Haberman's adjusted standardized residuals $z_{ij} \sim \mathcal{N}(0, 1)$, and individual cell $\chi^2$ contributions.
  3. Inferential Hypothesis Testing & Exact P-Values: Computation of Pearson's Chi-Square statistic $\chi^2 = \sum \frac{(n_{ij} - e_{ij})^2}{e_{ij}}$ with degrees of freedom $\text{df} = (r - 1)(c - 1)$, Likelihood Ratio deviance ($G^2$ statistic / Mutual Information), exact $p$-values computed via incomplete gamma functions (Lanczos approximation and Lentz continued fractions), non-parametric Monte Carlo permutation testing ($B = 1,000$ resamples), Fisher's exact test for $2 \times 2$ matrices, and effect size metrics (Cramér's $V$, Tschuprow's $T$, Contingency Coefficient $C$).
  4. Theoretical Concepts of Independence in Probability vs. Statistics: Rigorous demarcation between population-level measure-theoretic independence ($P(A \cap B) = P(A)P(B)$) and finite-sample statistical independence, accounting for stochastic noise, sample size scaling, characteristic function factorizations, and Cochran's asymptotic validity criteria ($e_{ij} \ge 5$).
  5. Statistical Association vs. Causality: Epistemological exploration of Reichenbach's Common Cause Principle, confounding bias, Simpson's Paradox (demonstrated through an interactive stratification model), and Judea Pearl's Causal Hierarchy (Association $P(Y \mid X)$ vs. Intervention $P(Y \mid \text{do}(X))$ vs. Counterfactuals) supported by an interactive Causal DAG Studio.

4. Epistemological Studio: Statistical Association vs. Causality

Theoretical Foundations: Independence in Probability vs. Statistics

1. Independence in Probability Theory (Population / Generative Model):
Let $(\Omega, \mathcal{F}, \mathbb{P})$ be a probability space. Two sub-$\sigma$-algebras $\mathcal{G}, \mathcal{H} \subseteq \mathcal{F}$ are independent if $\mathbb{P}(G \cap H) = \mathbb{P}(G)\mathbb{P}(H)$ for all $G \in \mathcal{G}, H \in \mathcal{H}$. For discrete random variables $X$ and $Y$, independence requires the joint probability mass function to factorize identically as the product of marginals: $$P(X = x_i, Y = y_j) = P(X = x_i) \cdot P(Y = y_j) \quad \forall (i, j)$$ Equivalently, the conditional distribution of $Y$ given $X$ is completely invariant to the realization of $X$: $$P(Y = y_j \mid X = x_i) = P(Y = y_j) \quad \forall x_i \text{ with } P(X = x_i) > 0$$ In terms of characteristic functions, independence holds if and only if: $$\varphi_{X, Y}(t_1, t_2) = \mathbb{E}\left[ e^{i(t_1 X + t_2 Y)} \right] = \varphi_X(t_1) \cdot \varphi_Y(t_2) \quad \forall (t_1, t_2) \in \mathbb{R}^2$$

2. Independence in Statistics (Finite Samples & Inferential Sampling Variability):
In an empirical sample of finite size $N$, the observed relative frequencies $\hat{p}_{ij} = n_{ij}/N$ almost never equal the theoretical product of sample marginals $\hat{p}_{i\cdot} \hat{p}_{\cdot j}$ exactly, even when the underlying data-generating process is strictly independent! Finite sampling produces random fluctuations (stochastic noise).

The statistical test of independence formalizes the question: Are the observed discrepancies $(n_{ij} - e_{ij})$ sufficiently small to be attributed entirely to random sampling error under $H_0$, or are they so large that $H_0$ is implausible? By the Central Limit Theorem and Fisher-Pearson asymptotics, the normalized squared sum of deviations converges in distribution: $$\chi^2 = \sum_{i=1}^r \sum_{j=1}^c \frac{(n_{ij} - e_{ij})^2}{e_{ij}} \xrightarrow{d} \chi^2_{(r-1)(c-1)} \quad \text{as } N \to \infty$$ Why $\text{df} = (r - 1)(c - 1)$? An $r \times c$ table has $rc - 1$ unconstrained cell probabilities (since $\sum p_{ij} = 1$). Under $H_0$, the model estimates $r - 1$ independent row parameters and $c - 1$ independent column parameters. Subtracting the estimated parameters from the total degrees of freedom yields: $$\text{df} = (rc - 1) - (r - 1) - (c - 1) = rc - r - c + 1 = (r - 1)(c - 1)$$

3. Association vs. Causality (The Ladder of Causation):
Statistical association is symmetric: $X \perp Y \iff Y \perp X$. Causality is asymmetric and directional: $X \to Y$ is fundamentally different from $Y \to X$. As formalized by Judea Pearl, statistical analysis of contingency tables operates strictly at Level 1 of the Causal Hierarchy (Associational: "Seeing" $P(Y \mid X)$). Inferring Level 2 (Interventional: "Doing" $P(Y \mid \text{do}(X))$) requires structural causal models, directed acyclic graphs (DAGs), or randomized controlled trials (RCTs) to block confounding backdoor paths ($X \leftarrow Z \to Y$).

Programmatic Expected Frequencies Under Independence function computeExpectedAndChi2(matrix, rSums, cSums, N) { let chi2 = 0.0, G2 = 0.0; const expected = [], residuals = []; for (let i = 0; i < matrix.length; i++) { expected[i] = []; residuals[i] = []; for (let j = 0; j < matrix[0].length; j++) { const o = matrix[i][j]; const e = (rSums[i] * cSums[j]) / N; expected[i][j] = e; const diff = o - e; chi2 += (diff * diff) / e; if (o > 0 && e > 0) G2 += 2.0 * o * Math.log(o / e); // Haberman's adjusted standardized residual ~ N(0, 1) const denom = Math.sqrt(e * (1.0 - rSums[i]/N) * (1.0 - cSums[j]/N)); residuals[i][j] = denom > 0 ? diff / denom : 0.0; } } return { expected, chi2, G2, residuals }; } // 2. Exact P-Value via Regularized Incomplete Gamma Function function chiSquarePValue(chi2, df) { if (chi2 <= 0) return 1.0; const s = df / 2.0, x = chi2 / 2.0; return x < s + 1.0 ? 1.0 - gammaLowerP(s, x) : gammaUpperQ(s, x); } // 3.
