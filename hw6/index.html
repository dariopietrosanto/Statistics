Executive Summary & Research Directives

In modern scientific computing, statistics, and cryptographic engineering, integration embodies two fundamentally different paradigms: geometric quadrature (numerical approximations of areas under curves) and measure-theoretic expectation ($\mathbb{E}[X] = \int_\Omega X \, d\mathbb{P}$).

This work explores both paradigms to an advanced research standard:

Part 1: Riemann vs. Lebesgue Integration Studio

Theoretical Foundations: Domain Slicing vs. Range Slicing

The Riemann Definition (1854): Partitions the domain $[a, b]$ into $N$ subintervals $a = x_0 < x_1 < \dots < x_N = b$ with width $\Delta x_i = x_i - x_{i-1}$. The upper and lower Darboux sums are defined as: $$U(\mathcal{P}, f) = \sum_{i=1}^N \left(\sup_{x \in [x_{i-1}, x_i]} f(x)\right) \Delta x_i, \qquad L(\mathcal{P}, f) = \sum_{i=1}^N \left(\inf_{x \in [x_{i-1}, x_i]} f(x)\right) \Delta x_i$$ By Lebesgue's Criterion for Riemann Integrability, a bounded function on a compact interval is Riemann-integrable if and only if its set of discontinuities $D_f$ has Lebesgue measure zero: $\mu(D_f) = 0$.

The Lebesgue Definition (1902): Henri Lebesgue observed that domain partitioning struggles whenever a function oscillates wildly, because the supremum and infimum within each interval diverge. Instead, Lebesgue partitioned the range $[y_{\min}, y_{\max}]$ into $M$ horizontal slices $y_0 < y_1 < \dots < y_M$. For each slice $[y_j, y_{j+1})$, we define its preimage in the domain: $$E_j = f^{-1}([y_j, y_{j+1})) = \{ x \in [a, b] : y_j \le f(x) < y_{j+1} \}$$ Approximating $f$ by simple functions $s_M(x) = \sum_{j=0}^{M-1} y_j^* \mathbf{1}_{E_j}(x)$, the Lebesgue integral is: $$\int_{[a, b]} f \, d\mu = \lim_{M \to \infty} \sum_{j=0}^{M-1} y_j^* \cdot \mu(E_j)$$ where $\mu(E_j)$ is the Lebesgue measure of the subset $E_j$.

Lebesgue's Coin Analogy: A Riemann counter picks up each coin scattered on a table from left to right, adding its value to the total. A Lebesgue counter sorts coins into piles by denomination (controimmagini), counts how many coins are in each pile (misura), multiplies count by denomination, and sums the piles.

The Pathological Crucible & Theoretical Dominance of Lebesgue

1. The Dirichlet Function Paradox: $$D(x) = \begin{cases} 1 & \text{if } x \in \mathbb{Q} \\ 0 & \text{if } x \notin \mathbb{Q} \end{cases}, \quad x \in [0, 1]$$ Because $\mathbb{Q}$ and $\mathbb{R}\setminus\mathbb{Q}$ are both dense in $[0, 1]$, every interval $[x_{i-1}, x_i]$ contains both rational and irrational numbers. Therefore: $$U(\mathcal{P}, D) = \sum_{i=1}^N 1 \cdot \Delta x_i = 1, \qquad L(\mathcal{P}, D) = \sum_{i=1}^N 0 \cdot \Delta x_i = 0$$ Because $U(\mathcal{P}, D) - L(\mathcal{P}, D) = 1$ for all partitions, the Riemann integral does not exist. If evaluated on a regular grid $x_k = k/N$, every point is rational and the sum equals $1.0$. If evaluated on a Weyl irrational orbit $x_k = (k \cdot \phi) \bmod 1$ ($\phi = \frac{\sqrt{5}-1}{2}$), every point is irrational and the sum equals $0.0$.

Lebesgue Resolution: Rationals are countable $\implies \mu(\mathbb{Q} \cap [0, 1]) = 0$. Irrationals have measure $1$. Preimages: $E_0 = D^{-1}(\{0\})$ has $\mu(E_0) = 1$; $E_1 = D^{-1}(\{1\})$ has $\mu(E_1) = 0$. The Lebesgue integral is unambiguously: $$\int_{[0, 1]} D \, d\mu = 0 \cdot \mu(E_0) + 1 \cdot \mu(E_1) = 0 \cdot 1 + 1 \cdot 0 = 0$$

2. Completeness of $L^p$ Spaces (The Riesz-Fischer Theorem): The space of Riemann-integrable functions $\mathcal{R}([a, b])$ equipped with the $L^1$ metric $d(f, g) = \int_a^b |f - g| dx$ is incomplete. Let $\{r_1, r_2, \dots\}$ be an enumeration of $\mathbb{Q} \cap [0, 1]$, and define $f_n(x) = \mathbf{1}_{\{r_1, \dots, r_n\}}(x)$. Each $f_n$ has only finitely many discontinuities, so $f_n \in \mathcal{R}([0, 1])$ with $\int f_n = 0$. The sequence $\{f_n\}$ is Cauchy in $L^1$, but its pointwise limit is the Dirichlet function $D(x) \notin \mathcal{R}([0, 1])$. Under the Lebesgue integral, the space $L^1([a, b], \mu)$ is a complete Banach space.

3. The Layer-Cake Representation (Cavalieri's Principle in Measure Theory): For any non-negative measurable function $f$: $$\int_{[a, b]} f \, d\mu = \int_0^\infty \mu(\{ x : f(x) > t \}) \, dt$$ This connects horizontal Lebesgue range slicing directly to the Fubini-Tonelli product measure on the subgraph $\{(x, t) : 0 \le t \le f(x)\}$.

Part 2: Numerical Normal CDF, Liouville's Theorem & Probit Studio

The Analytical Impossibility: Liouville's Theorem on Integration in Finite Terms

The Standard Normal Cumulative Distribution Function (CDF) is defined as: $$\Phi(z) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^z e^{-t^2 / 2} \, dt = \frac{1}{2} + \frac{1}{\sqrt{2\pi}} \int_0^z e^{-t^2 / 2} \, dt$$ Theorem (Joseph Liouville, 1835): If $f(x) = g(x) e^{h(x)}$ has an antiderivative expressible within an elementary extension of $\mathbb{C}(x)$, then there exists a rational function $R(x) \in \mathbb{C}(x)$ such that $\int g e^h dx = R e^h + C$. Differentiating yields: $$R'(x) + R(x) h'(x) = g(x)$$

Proof for the Gaussian Integrand $e^{-x^2}$: Here $g(x) = 1$ and $h(x) = -x^2$, so $h'(x) = -2x$. Liouville's equation becomes: $$R'(x) - 2x R(x) = 1$$

  1. Poles: If $R(x) = P(x)/Q(x)$ had a pole of order $m \ge 1$ at $x_0$, then $R'(x)$ would have order $m+1$, while $-2x R(x)$ would have order at most $m$. Their difference would have a pole of order $m+1 \ge 2$, contradicting the fact that $1$ has no poles. Thus $Q(x)$ is a constant, and $R(x) = P(x)$ is a polynomial!
  2. Degrees: Let $d = \deg(P) \ge 0$. The derivative has degree $\deg(P') = d - 1$. The term $-2x P(x)$ has degree $\deg(-2x P) = d + 1 \ge 1$. Thus $\deg(P'(x) - 2x P(x)) = d + 1 \ge 1$. But the right-hand side is $1$, which has degree $0$. Since $d + 1 \ge 1 \neq 0$, no such polynomial exists!
Hence, the antiderivative of $e^{-x^2}$ is non-elementary. This was generalized by the Risch Algorithm (1969).

The Error Function ($\text{erf}$) & The Inverse Normal CDF (Probit $\Phi^{-1}(p)$)

The Error Function bridges the analytical gap: $$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-u^2} \, du \implies \Phi(z) = \frac{1}{2} \left[ 1 + \text{erf}\left( \frac{z}{\sqrt{2}} \right) \right]$$ In risk modeling, penetration testing thresholds, and statistical hypothesis testing, the inverse problem is equally essential: finding the critical value $z_p = \Phi^{-1}(p)$ such that $\mathbb{P}(Z \le z_p) = p$.

Synthesis & Comparative Conclusions

Smooth Functions
Riemann = Lebesgue

For continuous functions, both approaches converge to identical integrals. Riemann is computationally $O(N)$ with negligible overhead.

Simple Functions
Lebesgue Exact in $O(M)$

When range slices align with step heights, Lebesgue yields zero approximation error regardless of domain complexity.

Pathological Cases
Riemann Fails (Dirichlet)

Dirichlet function produces $U=1 \neq L=0$ in Riemann. Lebesgue measure recognizes $\mu(\mathbb{Q})=0$, yielding rigorous $\int D = 0$.

Normal CDF Computation
Gauss-Legendre & A&S Win

Taylor erf suffers catastrophic subtraction cancellation for $|z| > 3$. A&S 7.1.26 and Gauss-Legendre offer optimal speed-precision tradeoffs.
