Executive Summary & Methodological Overview

In advanced applied mathematics, statistical theory, and computational physics, integration serves two fundamentally distinct purposes: geometric quadrature (approximating areas under curves) and measure-theoretic expectation (integrating random variables with respect to probability measures $\mathbb{E}[X] = \int_\Omega X \, d\mathbb{P}$).

This work investigates two foundational questions at the intersection of integration theory and numerical analysis:

  1. Exercise 1 – Riemann vs. Lebesgue Integration in Numerical Practice: We explore the philosophical and computational shift between Riemann integration (partitioning the domain into uniform intervals $\Delta x$) and Lebesgue integration (partitioning the range into slices $[y_j, y_{j+1})$ and computing the measure of their preimages $\mu(f^{-1}([y_j, y_{j+1})))$). We test both paradigms across 9 functions, ranging from smooth polynomials and trigonometric functions to improper integrals ($1/\sqrt{x}$) and pathological cases: the Dirichlet function (where Riemann fails completely while Lebesgue yields exactly $0$) and Thomae's popcorn function (where countable discontinuities preserve Riemann integrability).
  2. Exercise 2 – Numerical Computation of the Standard Normal CDF & Liouville's Theorem: The Gaussian cumulative distribution function $\Phi(z) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^z e^{-t^2/2} dt$ cannot be expressed in terms of elementary functions. We provide a rigorous algebraic proof using Liouville's Theorem on integration in finite terms (1835) and the Risch algorithm. We demonstrate why special functions like $\text{erf}(x)$ are defined as canonical transcendents, why numerical algorithms remain essential for hardware computation, and we benchmark 6 numerical architectures (Composite Trapezoidal, Simpson's 1/3, 10-point Gauss-Legendre, Taylor series expansion, Abramowitz & Stegun 7.1.26, and Laplace continued fractions) across speed, accuracy, and tail stability.

Part 1: Riemann vs. Lebesgue Integration

Theoretical Foundations: Domain Slicing vs. Range Slicing

The Riemann Definition (1854): Partitions the domain $[a, b]$ into $N$ subintervals $a = x_0 < x_1 < \dots < x_N = b$ with width $\Delta x_i = x_i - x_{i-1}$. The upper and lower Darboux sums are defined as: $$U(\mathcal{P}, f) = \sum_{i=1}^N \left(\sup_{x \in [x_{i-1}, x_i]} f(x)\right) \Delta x_i, \qquad L(\mathcal{P}, f) = \sum_{i=1}^N \left(\inf_{x \in [x_{i-1}, x_i]} f(x)\right) \Delta x_i$$ A bounded function is Riemann-integrable if and only if $\inf_{\mathcal{P}} U(\mathcal{P}, f) = \sup_{\mathcal{P}} L(\mathcal{P}, f)$. By Lebesgue's Criterion for Riemann Integrability, a bounded function on a compact interval is Riemann-integrable if and only if its set of discontinuities $D_f$ has Lebesgue measure zero: $\mu(D_f) = 0$.

The Lebesgue Definition (1902): Henri Lebesgue observed that domain partitioning struggles whenever a function oscillates wildly, because the supremum and infimum within each interval diverge. Instead, Lebesgue partitioned the range $[y_{\min}, y_{\max}]$ into $M$ horizontal slices $y_0 < y_1 < \dots < y_M$. For each slice $[y_j, y_{j+1})$, we define its preimage in the domain: $$E_j = f^{-1}([y_j, y_{j+1})) = \{ x \in [a, b] : y_j \le f(x) < y_{j+1} \}$$ Approximating $f$ by simple functions $s_M(x) = \sum_{j=0}^{M-1} y_j^* \mathbf{1}_{E_j}(x)$, the Lebesgue integral is: $$\int_{[a, b]} f \, d\mu = \lim_{M \to \infty} \sum_{j=0}^{M-1} y_j^* \cdot \mu(E_j)$$ where $\mu(E_j)$ is the Lebesgue measure of the subset $E_j$.

Lebesgue's Coin Analogy: Suppose a merchant wants to count the total value of coins scattered on a table. The Riemann approach picks up each coin in the order it lies from left to right on the table, adding its value to the total. The Lebesgue approach first groups the coins into piles by denomination (all pennies, all nickels, all dimes, all quarters), counts the number of coins in each pile (the measure of the preimage of that value!), multiplies the count by the denomination, and sums the products.

The Pathological Crucible: Dirichlet vs. Thomae Functions

1. The Dirichlet Function: $$D(x) = \begin{cases} 1 & \text{if } x \in \mathbb{Q} \\ 0 & \text{if } x \notin \mathbb{Q} \end{cases}, \quad x \in [0, 1]$$ Because both $\mathbb{Q}$ and $\mathbb{R}\setminus\mathbb{Q}$ are dense in $[0, 1]$, every subinterval $[x_{i-1}, x_i]$ contains both rational and irrational numbers. Consequently: $$U(\mathcal{P}, D) = \sum_{i=1}^N 1 \cdot \Delta x_i = 1, \qquad L(\mathcal{P}, D) = \sum_{i=1}^N 0 \cdot \Delta x_i = 0$$ Since $U(\mathcal{P}, D) - L(\mathcal{P}, D) = 1 \neq 0$ for every partition $\mathcal{P}$, the Riemann integral does not exist. In a computer simulation with a regular grid $x_k = k/N$, every node is a rational number, so a naive sampler outputs $1.0$; an irrational offset gives $0.0$.

Under the Lebesgue Integral: The set of rational numbers $\mathbb{Q} \cap [0, 1]$ is countable, so its Lebesgue measure is strictly zero: $\mu(\mathbb{Q} \cap [0, 1]) = 0$. The irrationals have measure $\mu([0, 1] \setminus \mathbb{Q}) = 1 - 0 = 1$. The function takes only two values: $\{0, 1\}$. The preimages are: $$E_0 = D^{-1}(\{0\}) = [0, 1] \setminus \mathbb{Q} \implies \mu(E_0) = 1, \qquad E_1 = D^{-1}(\{1\}) = [0, 1] \cap \mathbb{Q} \implies \mu(E_1) = 0$$ The Lebesgue integral is evaluated in a single step with zero ambiguity: $$\int_{[0, 1]} D \, d\mu = 0 \cdot \mu(E_0) + 1 \cdot \mu(E_1) = 0 \cdot 1 + 1 \cdot 0 = 0$$

2. Thomae's (Popcorn / Ruler) Function: $$T(x) = \begin{cases} \frac{1}{q} & \text{if } x = \frac{p}{q} \in \mathbb{Q} \text{ in lowest terms} \\ 0 & \text{if } x \notin \mathbb{Q} \end{cases}, \quad x \in [0, 1]$$ Remarkably, $T(x)$ is continuous at every irrational number and discontinuous at every rational number! Because the set of discontinuities is $\mathbb{Q} \cap [0, 1]$ (which has measure zero), by Lebesgue's Criterion, Thomae's function IS Riemann-integrable! Both the Riemann integral and the Lebesgue integral evaluate to exactly $0$.

Part 2: Numerical Computation of the Normal CDF & Liouville's Theorem

The Analytical Impossibility: Liouville's Theorem on Integration in Finite Terms

The Standard Normal Cumulative Distribution Function (CDF) is defined as: $$\Phi(z) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^z e^{-t^2 / 2} \, dt = \frac{1}{2} + \frac{1}{\sqrt{2\pi}} \int_0^z e^{-t^2 / 2} \, dt$$ Every calculus student asks: why is there no closed-form formula for $\int e^{-t^2/2} dt$ involving elementary functions ($\sin, \cos, \exp, \ln, \sqrt{\cdot}$)?

Theorem (Joseph Liouville, 1835): Let $K$ be a differential field of characteristic zero with derivation $D = d/dx$. If $g, h \in K$ with $h$ non-constant, and the integrand $g e^h$ has an antiderivative expressible within an elementary extension of $K$, then there exists a rational function $R \in K$ such that: $$\int g(x) e^{h(x)} \, dx = R(x) e^{h(x)} + C$$ Differentiating both sides with respect to $x$ yields Liouville's fundamental differential equation: $$R'(x) + R(x) h'(x) = g(x)$$

Proof for the Gaussian Integrand: For the Gaussian function $e^{-x^2}$, we have $g(x) = 1$ and $h(x) = -x^2$, so $h'(x) = -2x$. Liouville's equation requires finding a rational function $R(x) = \frac{P(x)}{Q(x)} \in \mathbb{C}(x)$ (with $P, Q$ coprime polynomials) satisfying: $$R'(x) - 2x R(x) = 1$$

  1. Pole Analysis: Suppose $Q(x)$ has a root at $x_0 \in \mathbb{C}$ of multiplicity $m \ge 1$. Then $R(x)$ has a pole of order $m$ at $x_0$. Its derivative $R'(x)$ has a pole of order $m + 1$, while the term $-2x R(x)$ has a pole of order at most $m$. Their difference $R'(x) - 2x R(x)$ must therefore possess a pole of order $m + 1 \ge 2$. However, the right-hand side is the constant polynomial $1$, which has no poles anywhere in $\mathbb{C}$. Thus $Q(x)$ cannot have any roots, which implies $Q(x)$ is a non-zero constant. Therefore, $R(x) = P(x)$ must be a polynomial!
  2. Degree Analysis: Let $P(x)$ be a polynomial of degree $d = \deg(P) \ge 0$. The degree of its derivative is $\deg(P') = d - 1$ (or $-\infty$ if $d=0$). The degree of the second term is $\deg(-2x P(x)) = 1 + d \ge 1$. Because the highest power $x^{d+1}$ cannot be canceled by $P'(x)$, the degree of the left-hand side is strictly: $$\deg(P'(x) - 2x P(x)) = d + 1 \ge 1$$ However, the right-hand side is $1$, whose degree is $0$. Since $d + 1 \ge 1 \neq 0$, no polynomial $P(x)$ can ever satisfy the equality!
Conclusion: By Liouville's Theorem, the antiderivative $\int e^{-x^2} dx$ cannot be expressed in terms of elementary functions. This theorem was later generalized into a complete algorithmic decision procedure by Robert H. Risch in 1969 (the Risch Algorithm).

The Role of Special Functions: Defining the Error Function ($\text{erf}$)

Because Liouville proved no elementary formula exists, mathematicians introduced a canonical special transcendent function, the Error Function: $$\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-u^2} \, du, \qquad \text{erfc}(x) = 1 - \text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_x^\infty e^{-u^2} \, du$$ Under the transformation $u = t / \sqrt{2}$, we obtain the exact analytical bridge to the Standard Normal CDF: $$\Phi(z) = \frac{1}{2} \left[ 1 + \text{erf}\left( \frac{z}{\sqrt{2}} \right) \right]$$ Why are numerical methods still necessary? Defining the name $\text{erf}(x)$ gives symbolic convenience, but digital processors (ALUs and FPUs) contain no hardware "erf" gates. Every real-world calculation—from $p$-values in hypothesis testing to portfolio Value-at-Risk (VaR)—must numerically approximate $\text{erf}(x)$ or $\Phi(z)$ within IEEE 754 floating-point constraints.

Synthesis & Comparative Conclusions

Smooth Functions
Riemann = Lebesgue

For continuous functions, both approaches converge to identical integrals. Riemann is computationally $O(N)$ with negligible overhead.

Simple Functions
Lebesgue Exact in $O(M)$

When range slices align with step heights, Lebesgue yields zero approximation error regardless of domain complexity.

Pathological Cases
Riemann Fails (Dirichlet)

Dirichlet function produces $U=1 \neq L=0$ in Riemann. Lebesgue measure recognizes $\mu(\mathbb{Q})=0$, yielding rigorous $\int D = 0$.

Normal CDF Computation
Gauss-Legendre & A&S Win

Taylor erf suffers catastrophic subtraction cancellation for $|z| > 3$. A&S 7.1.26 and Gauss-Legendre offer optimal speed-precision tradeoffs.
